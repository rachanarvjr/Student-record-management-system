# 🎓 Student Record Management System

## 📌 About the Project
This is a beginner-friendly Python project that manages student records using lists, tuples, dictionaries, and CSV files. It stores student details, writes records to text and CSV files, and reads data from CSV files for display.

## ✨ Features
- Stores student details using dictionaries.
- Organizes multiple student records using a list.
- Demonstrates tuples with course information.
- Saves student records in a text file (`students.txt`).
- Exports student records to a CSV file (`students.csv`).
- Reads and displays records from the CSV file.

## 🛠️ Technologies Used
- Python 3
- CSV module

## 🚀 How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

   ```bash
   python app.py
   ```

6. The program will create `students.txt` and `students.csv` and display the student records.

## 🎯 Objective
To demonstrate Python data structures and file handling through a simple student record management application.

## 📂 Project Files
- `app.py` — Main Python program.
- `students.csv` — Student records stored in CSV format.
- `students.txt` — Student records stored in text format.
